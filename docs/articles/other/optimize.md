# 性能优化

要了解前端性能优化,需要知道输入url到页面展示的整个过程，发生了什么，才能知道哪些地方可以优化。

### DNS解析

DNS解析就是将域名解析成IP地址，浏览器通过IP地址找到服务器。

### TCP连接

TCP连接就是浏览器和服务器之间的连接，浏览器通过TCP协议和服务器建立连接。

### 发送HTTP请求

浏览器通过HTTP协议向服务器发送请求，请求内容包括请求行、请求头、请求体。

### 服务器处理请求

服务器接收到请求后，会根据请求的内容进行处理，处理完成后返回响应，响应内容包括状态行、响应头、响应体。

### 浏览器解析响应

浏览器接收到响应后，会根据响应的内容进行解析，解析完成后将页面展示给用户。

## http优化有两大方向
- 减少请求次数
- 减少请求大小

### 减少请求次数

1. 合并文件，将多个CSS文件合并成一个CSS文件，将多个JS文件合并成一个JS文件。
2. 压缩文件，将CSS文件、JS文件、图片文件进行压缩，减少文件大小。
3. 懒加载，将页面中的图片、视频等资源进行懒加载，只有当用户滚动到页面底部时，才加载这些资源。
4. 缓存，将CSS文件、JS文件、图片文件等进行缓存，当用户再次访问页面时，可以直接从缓存中获取资源，减少请求次数。

### 减少请求大小

1. 压缩文件，将CSS文件、JS文件、图片文件进行压缩，减少文件大小。
2. 使用CDN，将资源部署到CDN上，用户可以从离自己最近的服务器获取资源，减少请求时间。
3. 使用HTTP/2，HTTP/2支持多路复用，可以同时发送多个请求，减少请求次数。

## webpack优化方案
1. 使用`webpack-bundle-analyzer`插件，分析打包后的文件大小，找出需要优化的地方。
2. 使用`code-splitting`，将代码分割成多个文件，按需加载，减少首次加载时间。
3. 使用`tree-shaking`，去除未使用的代码，减少打包后的文件大小。
4. 使用`webpack-parallel-uglify-plugin`插件，使用多核CPU进行代码压缩，提高压缩速度。
5. 使用`webpack-dll-plugin`插件，将第三方库打包成DLL文件，避免每次打包时都重新打包第三方库。

## 图片优化
1. 压缩图片，使用工具如TinyPNG、ImageOptim等。
2. 使用CSS Sprite技术，将多张图片合并成一张图片，减少请求次数。
3. 使用懒加载，只有当用户滚动到图片位置时，才加载图片。
4. base64编码，将图片转换为base64编码，减少请求次数。

## 浏览器缓存优化策略
1. 强缓存，通过设置`Cache-Control`和`Expires`头，告诉浏览器在指定时间内可以直接使用缓存，不需要向服务器发送请求。
2. 协商缓存，通过设置`ETag`和`Last-Modified`头，告诉浏览器在指定时间内可以直接使用缓存，不需要向服务器发送请求，如果缓存失效，则向服务器发送请求，服务器根据`ETag`和`Last-Modified`判断是否需要更新缓存。

## 本地缓存优化策略
1. 使用`localStorage`和`sessionStorage`，将数据存储在浏览器中，减少请求次数。
2. 使用`IndexedDB`，将大量数据存储在浏览器中，减少请求次数。
3. 使用`Service Worker`，将数据缓存到浏览器中，减少请求次数。
   
## css和js阻塞优化
1. 将CSS文件放在`<head>`标签中，将JS文件放在`<body>`标签的底部，避免CSS和JS阻塞页面渲染。
2. 使用`async`和`defer`属性，将JS文件异步加载，避免阻塞页面渲染。
3. 使用`CSS`预处理器，如Sass、Less等，将CSS代码分割成多个文件，按需加载，减少阻塞时间。

## DOM的优化原理和方案
1. 减少DOM操作，DOM操作是昂贵的，尽量避免频繁的DOM操作。
2. 使用虚拟DOM，虚拟DOM可以减少DOM操作，提高页面渲染性能。
3. 使用`requestAnimationFrame`，将DOM操作放在下一次重绘之前，避免页面卡顿。
4. 使用`CSS3`动画，避免使用JavaScript动画，因为JavaScript动画会阻塞页面渲染。
5. 减少回流和重绘，回流和重绘是昂贵的，尽量避免频繁的回流和重绘。
